Jake's Wines Logo Pack
======================

This pack was created from the approved Jake's Wines logo with a transparent background.

Folders
-------
01_Master
- Master transparent files for design and reuse.
- Use these when you need the highest-quality source version.

02_Web_Transparent
- Transparent PNG/WebP files for websites, landing pages, and general digital use.

03_Web_White_Background
- White-background PNG/JPG files for documents, email signatures, or platforms that do not handle transparency well.

04_Headers
- Wide transparent header versions sized for website nav bars, hero sections, and banner placements.

05_Social
- Square social-media formats with transparent and white-background options.

06_Icons_Favicons
- Small icon versions for favicons, app icons, browser tabs, and touch icons.

Recommended usage
-----------------
- Website header/logo area: 04_Headers
- General website/logo placement: 02_Web_Transparent
- Print mockups or simple documents: 03_Web_White_Background
- Social profiles/posts: 05_Social
- Browser tab/favicon: 06_Icons_Favicons/favicon.ico
- iPhone/iPad web shortcut: 06_Icons_Favicons/apple-touch-icon.png

Notes
-----
- Transparent files are best where possible.
- Use PNG when you need sharp transparency support.
- Use WebP for smaller website file sizes.
